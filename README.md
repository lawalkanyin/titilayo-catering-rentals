# Titilayo Catering & Rentals Website

This folder contains the complete static website for Titilayo Catering & Rentals.

## What's included
- Responsive mobile-friendly website
- Catering and buffet-service sections
- Photo gallery with click-to-enlarge images
- Six event/catering videos
- WhatsApp contact buttons using 0802 337 4314
- No database or server required

## Important hosting note
The files are GitHub-ready, but GitHub's current Pages documentation says GitHub Pages is not intended to be used as free web hosting for online businesses. For a real business website, use a hosting provider whose terms allow commercial sites (for example, Netlify's current Free plan).

## Deploying on Netlify
1. Create/sign in to a Netlify account.
2. Choose **Add new project / Import an existing project**.
3. Connect your GitHub repository, or upload this folder.
4. Publish the site.
5. Netlify will give you a public `*.netlify.app` link.
6. You can later connect a custom domain if you buy one.

## Updating the site
Replace/add files inside `media/` and edit `index.html` when you want to add more catalog items.
